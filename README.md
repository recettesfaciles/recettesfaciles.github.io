# Recettes Faciles

Site statique en français : des outils de cuisine gratuits (ajusteur de portions, convertisseur d'unités, estimateur de calories, substitutions d'ingrédients, planificateur de repas avec liste de courses), des tableaux de conversion et six guides de cuisine.

Technologies : HTML, CSS et JavaScript vanilla uniquement, sans bibliothèque externe.

Hébergement : GitHub Pages — https://recettesfaciles.github.io/
